# MT5 Scalper phone app

Android remote control for the MT5 scalper. The bot itself runs on a Windows PC or VPS next to
MetaTrader 5 (`mt5_control.py`); this app only shows its control page full screen.

The APK is built by `.github/workflows/mt5-app.yml` on every push that touches this folder.
Download it from the workflow run's artifacts (or the `mt5-app-latest` release), then install it
on the phone (allow "install unknown apps" for your browser).
